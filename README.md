# Дашборд доставки МТЗ на позиції — демо

> **Усі дані вигадані.** Групи (А–Д), частини (Т1001…), підрозділи, позиції, люди й цифри згенеровані для тестування.
> Реальні дані в цьому репозиторії не розміщуються і не повинні розміщуватися.

Прототип системи обліку доставки матеріально-технічних засобів: щоденні таблиці підрозділів → автоматичне зведення → інтерактивний дашборд.

**Відкрити дашборд:** `index.html` (через GitHub Pages або просто відкрити файл у браузері).

## Склад

| Шлях | Що це |
|---|---|
| `index.html` | Дашборд із вбудованими демо-даними. Працює офлайн, без зовнішніх бібліотек. |
| `dashboard-empty.html` | Той самий дашборд без даних — кнопкою «Відкрити CSV» завантажується свій `dostavky_flat.csv`. |
| `units/<група>/<в_ч>_доставка.xlsx` | 90 файлів частин (форма вводу): випадні списки, перевірка чисел і дат, автосума ваги, колонка «Дата запису». |
| `data/dovidnyk_pidrozdiliv.csv` | Довідник ієрархії: група → в/ч → підрозділ → позиція, колонка `path` для зведення й розмежування доступу. |
| `data/dostavky_flat.csv` | Зведення: 1 рядок = 1 доставка (13 554 записи, 28.09–07.10.2026). |
| `data/dostavky_long.csv` | Зведення: доставка × категорія МТЗ — зручно для графіків по категоріях. |
| `data/pomylky.csv` | Журнал проблем після зведення (у демо — порожній). |
| `scripts/zvedennia.py` | Щоденне зведення всіх файлів частин в одну таблицю з перевірками. |
| `scripts/onovyty_shablony.py` | Розширення: нова частина/позиція з довідника → новий файл і оновлені списки. |
| `scripts/generate_test_data.py` | Генератор цього демо-набору. |

Обсяг демо: 5 груп, 90 частин, 264 підрозділи, 1 600 позицій, 10 днів.

## Можливості дашборду

- Фільтри: період (пресети або дати), група → в/ч → підрозділ, спосіб доставки, категорія МТЗ, поріг тривоги.
- Показники: доставки, тонни, кг на 1 в/с на добу, покриття позицій, позиції без доставки, зриви, запізнілі записи.
- Автоматичні висновки по вибірці (найслабший підрозділ, тренд, лідер за зривами).
- Динаміка по днях, порівняння з провалюванням по рівнях, теплова карта з пропусками, тривоги, таблиці, експорт вибірки.
- Світла й темна тема.

## Як працює щоденний цикл

```bash
pip install openpyxl

# 1. Люди дописують рядки у свої файли units/...
# 2. Раз на добу — зведення:
python scripts/zvedennia.py units data/dovidnyk_pidrozdiliv.csv data
# 3. data/dostavky_flat.csv → у dashboard-empty.html (кнопка «Відкрити CSV») або в Superset

# Додати частину/позицію: рядок у data/dovidnyk_pidrozdiliv.csv, потім
python scripts/onovyty_shablony.py data/dovidnyk_pidrozdiliv.csv units
```

Зведення щоразу перебудовується з усіх файлів (без дублікатів); `stan_zapysiv.csv` у теці результату зберігає, коли кожен рядок з'явився вперше.
